Install

git clone https://github.com/henrynkoh/garage2afh_ai.git
cd garage2afh_ai
python3 -m pip install ezdxf pypdf openpyxl
python3 g2a.py new "123 Jane Doe St, Tumwater WA 98512" --parcel 40380000700 --lot-sf 9411
python3 g2a.py build 123-jane-doe-st
python3 g2a.py bind   123-jane-doe-st
python3 g2a.py check  123-jane-doe-st

Blender is optional and only used for IFC export. Generated drawings are drafts; code compliance and signatures stay with the licensed human.
